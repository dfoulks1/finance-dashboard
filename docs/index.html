ASF Financial Dashboard — Development Docs¶

A custom financial dashboard for The Apache Software Foundation (a 501(c)(3) nonprofit), giving board members and finance volunteers visibility into cash position, reserves, spending patterns, and budget variance.

AI-assisted, human-reviewed

This is an AI-powered development project. Code and documentation are produced with generative AI tooling driven by a structured prompt workflow, and every change is reviewed and vouched for by a named human before it lands. See the AI Contribution Guide for the rules we work under, including ASF generative-AI policy compliance.

The core questions¶

The dashboard exists to answer four questions about ASF finances:

  1. Money we have — current cash and reserve position.
  2. Money we should not spend — the restricted reserve.
  3. Money we should spend — budgeted but unspent operating funds.
  4. Why haven't we spent it? — budget-vs-actual variance with context.
